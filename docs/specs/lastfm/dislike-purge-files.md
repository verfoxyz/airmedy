# 任务：不喜欢页「彻底删除」开关（删本地音频与封面）

> 状态：✅ 已完成（`dislike_purge_files` 迁移 000113；开启后 Dislike 经 `library.PurgeDislikeTargets` 复用 `DeleteTrackFile` 删除音频/无引用封面/流缓存/歌词并推进播放；确认弹窗区分「删除并标记」与「仅标记」，艺人级需勾选确认；推荐数据清理沿用 dislike-purge 的事务实现；Go/Vue 测试覆盖）
> 目的：不喜欢时可以选择连本地音频、封面、缓存一起删除，只保留过滤用的名称/歌手信息
> 关联：`dislike-purge.md`、`dislike-tag.md`、`library`（删除文件）

---

## 1. 开关

- 位置：设置 →「不喜欢」页面右上角；
- 文案：`settings.dislike_purge_files`「不喜欢时同时删除本地文件」；
- 默认：**关闭**；
- 持久化：`app_settings.dislike_purge_files`（迁移 `000113`，`INTEGER NOT NULL DEFAULT 0`）；
- 开启时页面显示警告说明：删除不可恢复。

## 2. 行为

### 2.1 开关关闭（现有行为）

只删除推荐源数据（items / match_cache / 候选池），本地文件保留。

### 2.2 开关开启

在关闭模式的基础上，额外执行：

1. **本地音频**：按 `match_key`（曲目）或艺人 key（艺人级）找到本地 `tracks` 行：
   - 标记该行 `availability=deleted`（或直接删除行，取决于现有删除流程）；
   - 删除磁盘文件（与「删除文件」同一实现，保证索引/播放列表/统计一致）；
   - 若文件是用户手动移动过的路径，按数据库路径删除；
2. **封面**：删除 `tracks.artwork_key` / `albums.artwork_key` 对应的图片文件；无其它引用时删除文件，有引用则保留；
3. **流缓存**：删除该曲 `stream_cache` 行与缓存文件；
4. **歌词**：删除该曲已保存歌词（可选，默认删）；
5. **保留**：`dislikes` 行（`title / artist / match_key`）、播放历史（可选保留，默认保留用于统计）。

### 2.3 正在播放时

- 若该曲正在播放：先停止播放并切换到下一首，再执行删除；
- 若即将删除的是当前队列曲目：从队列移除。

### 2.4 艺人级不喜欢

开启时删除该艺人**所有本地曲目**——需要二次确认（输入或勾选“我了解将删除 N 首”）。

## 3. 确认流程

- 开关开启后，每次点「不喜欢」弹确认框：
  - 显示将要删除的曲目数/文件；
  - 「删除并标记不喜欢」/「仅标记不喜欢」；
- 确认后执行，失败部分回滚（推荐数据删除与文件删除分开报告）。

## 4. 测试

**Go**

- 开关关闭：只删推荐数据，文件仍在；
- 开关开启：文件、封面、流缓存、歌词被删除；
- `dislikes` 行保留 title/artist；
- 艺人级删除全部本地曲目并二次确认；
- 正在播放的曲目：停止后删除；
- 事务/删除失败时返回明确错误，不静默；
- 迁移 up/down。

**前端**

- 开关默认关闭、状态持久化；
- 开启后确认框与警告文案；
- 12 语言新增：`settings.dislike_purge_files`、`settings.dislike_purge_files_hint`、`settings.dislike_purge_confirm`、`settings.dislike_purge_confirm_artist`、`settings.dislike_purge_only_mark`。

**人工**

1. 关闭开关 → 不喜欢一首，文件仍可播放；
2. 打开开关 → 不喜欢一首，文件从磁盘删除、封面消失，设置页仍显示名称；
3. 艺人级不喜欢 → 确认框显示数量后全部删除；
4. 取消开关后行为恢复。

## 5. 验收

- 自动：§4 全绿；
- 人工：§5 四条成立；
- 删除不可逆，确认流程不可省略。

## 6. 风险

- 删除文件影响其他功能（歌单、统计、播放列表）——必须复用现有删除实现；
- 艺人级删除范围大，必须二次确认；
- 封面文件可能被多首歌引用，只在无引用时删除；
- 若文件被其它程序占用，删除失败需提示并保留标记。
