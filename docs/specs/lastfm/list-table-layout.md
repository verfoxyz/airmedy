# 任务：Last.fm 歌单详情改为表头 + 列布局

> 状态：✅ 已完成（`TopTrackRow` 改为固定 56px 的 # / 标题 / 艺人 / 状态 / 操作 行，`LastFmListView` 增加 sticky 表头；窄容器隐藏艺人列并显示副行；五种状态 chip、行号/播放高亮、标题与双击播放、保存/收藏切换、⋯ 打开完整菜单；Vue 测试覆盖列顺序、状态、禁用与动作）
> 目的：把当前“卡片式行”改为「# / 标题 / 艺人 / 标签 / 操作」的表格式列表，信息更整齐
> 关联：`recommendation-lists.md`、`row-context-menu.md`、`catalog/ui`

---

## 1. 目标布局

```
#    标题                 艺人              标签            操作
1    新.与天齐            指尖笑            [来自 tx]      ▶  ⬇  ⋯
2    HIT THE JACKPOT!…   GameboyJones      [匹配中]       ⋯
3    misery.             pupsies           [已在库中]     ▶  ✕  ⋯
```

- 表头固定（滚动容器顶部 sticky），行高与 `TrackTable` 一致；
- 列宽（艺人位于表格中间，标题与艺人同享剩余空间）：

```
48px | 标题（含 40px 封面）minmax(180px, 1.2fr) | 艺人 minmax(140px, 1fr) | 状态 120px | 操作 96px
```

- 标题与艺人都是自适应列，状态/操作靠右固定；
- 窄容器（< @md）：艺人列隐藏，列宽退化为 `48px | minmax(0,1fr) | 112px | 80px`；
- 列模板必须**抽成共享常量**（表头与行共用），避免两处不同步导致错位；
- 使用现有虚拟列表机制（行高常量在 `catalog/ui` 中定义）。

## 2. 列定义

| 列 | 内容 | 说明 |
|---|---|---|
| `#` | 行号（1 起）或播放状态 | 当前播放行显示音量/播放图标 |
| 标题 | **封面缩略图（左）+ 曲名**（单行截断，hover 显示完整） | 封面并入标题列，不单独占列；点击播放（可播时） |
| 艺人 | 艺人名（多艺人用 `、` 连接，截断） | 点击打开艺人页（已匹配时） |
| 标签 | **匹配状态 chip**：匹配中 / 来自源 / 已在库中 / 无匹配 / 此曲有疑问 | 与行菜单状态一致；`已取消/失败` 不进入 |
| 操作 | 播放、保存/收藏、更多（⋯ 打开完整右键菜单） | hover 显示 |

- 「标签」本期是匹配状态；后续可扩展为风格标签（Last.fm tags），预留列配置。

### 2.1 封面缩略图

- 位置：标题列最左侧，尺寸 **40×40**、`rounded-md`，与标题基线垂直居中；
- 不单独设列，表头仍为 `# / 标题 / 艺人 / 状态 / 操作`；
- 无封面时显示占位图标（同 `LastFmCover` 现有占位）；
- 图片懒加载（`LazyImg`），失败回退占位，不改变行高；
- 行高保持 56px 不变。

## 3. 交互

- 行 hover：`hover:bg-foreground/[0.04]`；
- 双击行 = 播放；
- 右键 = 现有 `useLastFmRowMenu` 完整菜单；
- 行内“更多”按钮 = 同一菜单；
- 匹配中的行：标题/艺人不加链接，播放按钮置灰；
- 保存/收藏按钮随状态切换图标与文案（已在库 = 收藏态）。

## 4. 与现有代码的关系

- 用列布局替换 `LastFmListView.vue` 里的 `TopTrackRow`；
- 可以复用 `TrackTable` 的表头/列样式，但数据源是 `TopTrackItemDTO`，需要一个轻量适配（不注册为 `TrackDTO`）；
- 保留搜索过滤（标题/艺人）与「加载更多」；
- 保留悬浮栏（sticky toolbar）；
- 手机/窄屏：隐藏「艺人」列，标题下显示艺人副行。

## 5. 测试

**前端**

- 表头渲染与列顺序；
- 行号连续、播放行高亮；
- 状态 chip 文案与颜色对应五种状态；
- 操作列按钮与右键菜单动作一致；
- 窄屏隐藏艺人列并显示副行；
- 播放/保存/收藏/更多按钮的禁用规则。

**人工**

1. 打开歌单详情 → 表头与列对齐，滚动时表头固定；
2. 点击标题播放；右键菜单可用；
3. 各状态的 chip 显示正确；
4. 窄屏布局不溢出。

## 6. 验收

- 自动：§5 全绿；
- 人工：§6 四条成立；
- 视觉与本地 `TrackTable` 一致（行高、hover、字号）。

## 7. 风险

- 虚拟列表 + 动态行高会破坏对齐，必须固定行高；
- 状态 chip 宽度变化可能挤压标题，需要最小宽度与截断；
- 若后续加“风格标签”列，需改为可配置列。
