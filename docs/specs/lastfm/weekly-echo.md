# 任务：Last.fm 页新增「每周回响」歌单

> 状态：✅ 已完成（kind `weekly_echo:<from>` 每周一存、chart list 24h 缓存、详情页周切换与 playcount、自动刷新开关存 localStorage；Go/前端测试覆盖）
> 目的：按周回顾自己那段时间的常听曲目，并可直接播放/保存
> 关联：`recommendation-lists.md`（歌单卡片与持久化）、`discovery.md`

---

## 1. 能力确认（已实测）

- `user.getWeeklyChartList?user=<用户名>` 返回所有可用的周区间（`from`/`to` Unix 秒，从 2007 年至今）；
- `user.getWeeklyTrackChart?user=<用户名>&from=…&to=…` 返回该周曲目与 `playcount`（实测最新一周 25 首，含封面）；
- 注意：**必须使用 chart list 给出的区间**，任意 from/to 会返回空数组。

## 2. 数字与卡片

- 新 kind：`weekly_echo`；
- 卡片文案：**每周回响**；
- 卡片显示：标题、曲目数、封面拼图（取该周前 1–4 首的封面），样式与其它歌单卡片一致（AlbumCard 风格）；
- 卡片副标题：周区间（如 `11/09 – 11/16`）；
- 卡片顺序建议：发现 → **每周回响** → 为你推荐 → 常听曲目。

## 3. 数据与行为

1. 首次进入：请求 `getWeeklyChartList`（1 次，缓存 24h），取**最近一个已结束的周**；
2. 请求该周 `getWeeklyTrackChart`（1 次），写入持久化行（kind=`weekly_echo`，附带 `week_from/week_to`）；
3. 行字段：标题、艺人、专辑、时长、封面、`playcount`；
4. 匹配：与现有列表共用五源匹配队列；未匹配行保留显示（与「常听曲目」一致）；
5. **历史周浏览**：详情页顶部提供「上一周 / 下一周」切换：
   - 切换时按该周区间请求一次并持久化（每周只请求一次，之后读库）；
   - 没有更早/更新数据时按钮置灰；
6. 新周到来：每天检查一次 chart list（或打开页面时检查 `weekly_echo` 的 `week_to` 是否过期），发现新周才更新卡片。

## 4. 持久化

- 复用现有两张表；
- `kind` 编码周区间：`weekly_echo:<from>`，这样每周一份，切换历史周无需覆盖；
- 卡片 summary 取“最新周”的那一份；
- 行保留 `playcount`（`lastfm_recommendation_items` 需要新增 `play_count INTEGER DEFAULT 0` 或放入 JSON 扩展列）。

## 5. 刷新策略

- 周数据**不可变**，不需要 TTL 刷新；
- 只在新的一周出现时自动构建一次；
- 手动刷新：重新拉取当前所选周；
- 页面右上角「自动刷新」开关同样生效（关闭后不检查新周）。

## 6. 前端

- 卡片：每周回响（封面拼图 + `曲目数 · 周区间`）；
- 详情页 `/lastfm/lists/weekly_echo`：
  - 与专辑详情一致的 hero / 搜索 / 悬浮栏；
  - 顶部周切换（上一周 / 下一周 + 区间文本）；
  - 行右侧显示该周播放次数（`playcount`）；
  - 状态 chip 与其它列表一致（匹配中/来自源/无匹配/已在库中）；
- 12 语言新增：`lastfm.weekly_echo`、`lastfm.week_prev`、`lastfm.week_next`、`lastfm.plays_count`。

## 7. 请求预算

| 动作 | 请求 |
|---|---|
| 首次构建 | 2（chart list + 一周数据） |
| 切换一周 | 1 |
| 新周检查 | 1 / 天（可并入页面打开时的检查） |

## 8. 测试

**Go**

- 解析 chart list，取最近已结束周；
- 用正确区间请求并解析 `playcount`/封面；
- 切换周写入独立的 `kind` 行，互不覆盖；
- 新周出现时卡片更新；
- 无历史周时返回空并显示空状态；
- 匹配与其它列表共用缓存。

**前端**

- 卡片渲染（周区间、曲目数）；
- 详情页周切换按钮状态与数据刷新；
- playcount 展示；
- 自动刷新开关生效。

**人工**

1. 打开 Last.fm 页出现「每周回响」，显示最近一周；
2. 点开能看到该周曲目与播放次数；
3. 切上一周/下一周正常；
4. 跨周后重新打开能看到新的一周。

## 9. 验收

- 自动：§8 全绿；
- 人工：§8 四条成立。

## 10. 风险

- 周区间必须来自 chart list，任意区间会为空；
- 历史周很多（2007 年起），只按需加载，不预取；
- `playcount` 需要在持久化表中新增字段（迁移 `000106`），旧行默认 0。
