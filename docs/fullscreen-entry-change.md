# 需求：全屏入口改为点击封面，歌曲信息成为全屏内的一个页签

> 状态：待开工
> 影响面：播放条（`PlayerFooter.vue`）、全屏播放器（`FullScreenPlayer.vue`）、歌曲信息（`TrackInfoDrawer.vue`）、
> 播放器 store、12 个 locale
> 硬约束：**AI 不做图形化测试**；界面由人工确认。

---

## 1. 目标

两件事：

1. **全屏入口**从播放条的图标挪到**点击封面**；
2. **歌曲信息**不再以抽屉/弹窗形式打开，而是成为**全屏内的第三个页签**——
   看歌曲详情时**不退出全屏**。

| 位置 | 现状 | 改为 |
|---|---|---|
| 播放条封面 | 单击 → 打开歌曲信息抽屉 | 单击 → **进入全屏** |
| 播放条右侧「最大化」按钮 | 进入全屏 | **删除** |
| 全屏页签 | `歌词` / `播放列表` 两个 | 增加第三个 `歌曲详细` |
| 全屏内点标题/歌手 | **退出全屏**并打开抽屉 | 切到 `歌曲详细` 页签，留在全屏 |
| `歌曲信息` 抽屉入口（播放条） | 封面单击 | 全屏内页签（播放条不再提供） |

**不做**：迷你播放器（`MiniPlayer.vue`）不动；封面右键菜单不动；歌词页签行为不动。

---

## 2. 交互规格

### 2.1 播放条封面

- **单击 / Enter / Space** → `store.setPlayerMode('fullscreen')`。
- 封面变成**可聚焦按钮**：`aria-label` = 曲名 + "进入全屏"；键盘可 Tab 聚焦。
- **hover / focus 提示**「点击进入全屏」：用现有 tooltip 机制，不新造样式。
- hover 时可给一层极轻的主题色遮罩（如 `bg-foreground/[0.04]` 同级别，禁止白/黑透明度叠加）。
- **没有当前曲目时不进入全屏**，按钮 `aria-disabled`，不展示提示。
- 右键菜单保留。

### 2.2 删除「最大化」按钮

- 移除播放条里调用 `setPlayerMode('fullscreen')` 的按钮。
- `player.fullscreen` 键若不再引用，可以保留（无害）；删除必须 12 语言同批。

### 2.3 全屏新增「歌曲详细」页签

**页签顺序**：`歌词` · `播放列表` · `歌曲详细`（图标分别 Mic2 / ListMusic / Info）。

行为：

- 选中后，右侧栏内联渲染歌曲详情（与现在的抽屉内容一致），**不打开抽屉、不退出全屏**；
- 再次点击当前页签 → 关闭右侧栏（与现有「歌词/播放列表」的开关语义一致）；
- 全屏内点击**标题/歌手/专辑**任意一处 → 切到 `歌曲详细` 页签（不再调用会把模式切回 `sticky` 的旧函数）；
- **Esc**：右侧栏打开时先关右侧栏，再按一次才退出全屏；
- 没有当前曲目：页签可点，但内容区显示空态（"当前没有播放的曲目"），不报错。

**抽屉与页签的关系**

- 歌曲信息的**内容**抽成可复用面板（例如 `PlayerTrackInfoPanel.vue`），
  抽屉（`TrackInfoDrawer.vue`）与全屏页签共用同一份渲染；
- 全屏模式下不再弹抽屉：全屏里凡是"打开歌曲信息"的入口，一律切页签；
- 非全屏场景（若仍有入口，例如右键菜单的"歌曲信息"）继续用现有抽屉，不改动。

**store 需要的最小改动**

- 右侧栏状态从 `isLyricsOpen` / `isQueueOpen` 两态扩展为三态（新增 `isInfoOpen`），
  `closeAllDrawers()` 一并覆盖；
- `activeTab` 的 getter/setter 增加 `info` 分支；
- **不要**让 `openTrackInfo()` 再去切换 `playerMode`——全屏内切页签，全屏外才开抽屉。

## 3. 边界与无障碍

| 场景 | 行为 |
|---|---|
| 空队列 / 无当前曲目 | 封面不进全屏；`歌曲详细` 页签显示空态 |
| 全屏中切歌 | `歌曲详细` 页签停留，内容随当前曲目刷新 |
| Esc | 先关右侧栏，再按退出全屏 |
| 键盘 | 封面可 Tab 聚焦 + Enter/Space；页签可方向键切换（沿用现有 TabSwitcher 行为） |
| 主题 | 面板背景、分隔线、正文颜色全部取自现有 token；亮/暗/黑三套都要看 |

## 5. 验收

**自动**

- `pnpm --filter @airmedy/frontend test`（新增/更新 spec 通过）
- `vue-tsc --noEmit` 干净
- 12 locale 键位对照测试通过

**人工（由人做，AI 不做）**

1. 点播放条封面 → 进入全屏；hover 与键盘聚焦都能看到「点击进入全屏」；
2. 播放条不再有最大化按钮；
3. 全屏里页签为 `歌词 / 播放列表 / 歌曲详细`，点「歌曲详细」在右侧显示详情，**不退出全屏**；
4. 全屏里点标题或歌手 → 自动切到「歌曲详细」；
5. Esc：先关右侧栏，再退出全屏；
6. 空队列时点封面不进全屏，页签显示空态；
7. 封面右键菜单仍可用；
8. 亮/暗/黑三主题各看一眼。

## 6. 风险

| 风险 | 应对 |
|---|---|
| 页签从 2 个变 3 个，右侧栏变窄 | 面板用现有宽度，内容纵向滚动；窄窗口下先看实际效果再调 |
| 抽屉与面板两套渲染走偏 | 必须共用同一个内容组件，不允许复制一份 |
| 全屏入口更隐蔽 | hover/focus 提示是必须项 |
| `openTrackInfo` 语义分裂 | 在 store 里显式区分"全屏内切页签"与"全屏外开抽屉"，不要靠调用点判断 |
