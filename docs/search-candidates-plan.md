# 需求：搜索候选（关键词联想）——本地 + 云端

> 状态：待开工
> 范围：主搜索页搜索框；本地与云端**一次做完**，不分期
> 硬约束：AI 不做图形化测试；交互由人工确认。
> 相关：`aggregate-search-tx-kg-plan.md`（kg 源与多选、排行）

---

## 1. 目标

在搜索框下方给**关键词候选**，本地与云端都做：

| 来源 | 取什么 | 说明 |
|---|---|---|
| 本地 | **按页面作用域**取（见 §2.1） | 离线可用，模糊匹配 |
| 云端 | kg 的联想接口（`searchtip.kugou.com`） | 只返回关键词字符串，无封面、无 ID |

**候选就是关键词**，不是曲目行。有缩略图就显示缩略图，没有就不显示——不为了缩略图额外发请求。

---

### 2.1 本地候选的作用域

本地候选**只搜当前页面所属的类型**，不跨类型：

| 页面 | 本地候选来自 |
|---|---|
| 主搜索页 / 全局搜索 | 曲目 + 艺术家 + 专辑（三类混排） |
| **曲目页（歌曲页）** | **全部三类**——曲目页的搜索本来就是"找任何东西" |
| **艺术家页** | **只有艺术家** |
| **专辑页** | **只有专辑** |
| 其他实体页（歌单等） | 该页面对应的实体类型，遵循同一条规则 |

理由：在艺术家页输入"周"，用户要的是艺术家，混进曲目和专辑只会稀释结果。
云端候选不受此限——它本来就是关键词，不区分类型。

## 2. 候选列表

固定 **最多 5 行**（可配置，见 §5），每行：`缩略图（可选） + 关键词 + 来源标签`。

按匹配度混排，来源标签只有两种：`本地` / `kg`（以后有 tx 就多一个 `tx`）。

```
1  晴天            [本地]
2  晴天 (Live)     [kg]
3  周杰伦 晴天     [kg]
...
```

- 点击候选 = **填入搜索框并执行搜索**（不跳转、不播放）；
- 同分时本地优先（离线可用）；
- 重复关键词只保留一条，标签取第一个来源。

**缩略图规则**：kg 的联想接口不返回图片 → kg 行没有缩略图；本地行可以用库里已有的封面缓存
（有就显示，没有就占位）。不会为了候选去抓封面。

---

## 3. 候选来源怎么选：搜索框自己的多选抽屉

**候选的来源选择与搜索结果页的源筛选是两套独立状态**，互不影响：

| 位置 | 控制什么 | 形态 |
|---|---|---|
| **搜索框旁的下拉抽屉** | 候选要问哪些源（本地始终参与） | 多选，勾选 `kg` 就出 kg 候选，不勾就没有 |
| **搜索结果页的源 chips** | 正式搜索查哪些源 | 保持现有形态（`全部 / wy / kg`） |

两者不联动：在抽屉里取消 kg，不会改变结果页的筛选；反过来也一样。选择各自持久化。

## 3.1 云端候选的开关

- 位置：聚合搜索插件设置，默认**关闭**；关闭时抽屉里的云端源灰显、不可勾选；
- 关闭：本地搜索**不发任何网络请求**；
- 开启：额外请求 kg 联想，**防抖放宽到 1s**（本地仍 250ms）。

---

## 4. 交互规则

| 项 | 规则 |
|---|---|
| 防抖 | 本地 250ms；开启云端后 1000ms |
| 最小长度 | 中文 ≥1 字；英文 ≥2 字母 |
| 取消 | 新输入到达时丢弃旧响应（请求版本号），旧结果不得覆盖新结果 |
| 键盘 | ↑/↓ 移动、Enter 填入并搜索、Esc 关闭；`role="combobox"`、`aria-expanded` |
| 空输入 | 显示**最近搜索**（最多 8 条，只存文字），带「清除」入口 |
| 失败 | 云端失败只丢云端候选，不弹错 |
| 过滤框 | 本次不接入（专辑/艺术家/歌单筛选保持现状） |

---

## 5. 最大显示条数

插件设置里增加 `max_suggestions`（默认 5），控制候选下拉最多显示几条。

> **实现依赖**：现有插件设置只支持开关（`type: "switch"`）。要支持数字需要扩展设置类型
> （`type: "number"`，带 min/max/step）。见 §7 的待确认项。

## 6. 工作分解

| # | 任务 | 估时 |
|---|---|---|
| S1 | 本地候选：Bleve 模糊查询，**按页面作用域**（主搜索页三类混排 / 艺术家页仅艺术家 / 专辑页仅专辑），含权重、50ms 超时、上限 | 1.5 天 |
| S2 | 云端候选：kg 联想接口接入（`searchtip.kugou.com`，需要 Referer） | 0.5 天 |
| S3 | 候选组件：混排、标签、键盘、最近搜索、清除 | 1.5 天 |
| S4 | 插件设置：`suggest_in_local`（开关）+ `max_suggestions`（数字）+ **扩展 `type: "number"` 设置类型**（与结果上限共用） | 1.5 天 |
| S5 | 接线：本地/云端防抖、开关联动、失败降级 | 0.5 天 |
| S6 | 12 locale + 测试 + 文档 | 1 天 |

**合计约 5.5–6 天。**

## 7. 已确认

1. **数字型设置**：本轮扩展 `type: "number"`（带 min/max/step），候选条数与结果上限共用。
2. **本地候选范围**：按页面作用域——主搜索页取曲目 + 艺术家 + 专辑，艺术家页只取艺术家，专辑页只取专辑。
3. **候选的来源选择**：搜索框自己的多选抽屉，与结果页的源 chips **互不影响**（见 §3）。

---

## 8. 验收

**自动**

- 组件：输入触发一次查询；快速连续输入只保留最后一次结果；
- 组件：↑/↓/Enter/Esc 与 `aria-*` 正确；重复关键词去重、标签正确；
- store：艺术家页只返回艺术家、专辑页只返回专辑、主搜索页返回三类；
- store：开关关闭时本地输入**不产生网络请求**；开启后防抖 1000ms；
- 契约：kg 联想解析（`HintInfo` 提取、空返回、错误分类）。

**人工（由人做，AI 不做）**

1. 输入"晴"：出现候选，本地行带 `本地` 标签、kg 行带 `kg` 标签；
2. 点候选：搜索框变成该关键词并开始搜索；
3. 关掉插件开关：不再出现 kg 行，且无网络请求；
4. 空输入：显示最近搜索与「清除」；
5. 快速连续输入：无旧结果闪回；
6. 亮/暗/黑三主题下浮层可读。
